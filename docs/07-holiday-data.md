# 07단계 공휴일 데이터

- 앱에 포함한 연도: 2026년, 2027년. 2028년 이후는 공식 연간 자료가 확인·반영되기 전까지 날짜를 만들지 않는다.
- 2026 기준: [한국천문연구원 2026년 월력요항 발표](https://www.kasi.re.kr/kor/post/newsMaterial/32031).
- 2027 기준: [우주항공청 2027년 월력요항 발표](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431).
- 2026년 노동절·제헌절은 이후 공휴일 지정이 발표되어 2027년 월력요항 안내에 명시된 2026년 적용 내용을 반영했다.
- 매년 우주항공청의 월력요항/관보 발표를 확인한 뒤 `apps/mobile/src/lib/calendarItems.ts`의 해당 연도 자료를 갱신하고 공휴일 단위 테스트를 추가한다. 음력 날짜를 앱에서 계산하거나 365일 간격으로 공휴일을 반복하지 않는다.
- 포함 데이터는 전국 관공서 공휴일, 대체공휴일 및 해당 연도 선거일처럼 월력요항에 명시된 단일 공휴일이다. 지역 공휴일과 일반 기념일은 포함하지 않는다.
