# Codex 커플앱 스타터 패키지

## 들어 있는 파일
- `CODEX_FIRST_TASK.md`: Codex 패널에 그대로 붙여넣을 첫 작업 지시문
- `docs/references/private/*.jpg`: 실제 데모의 8개 화면 이미지

## 사용 방법
1. Cursor에서 기존 앱 프로젝트 또는 새 빈 프로젝트 폴더를 연다.
2. 이 ZIP을 그 폴더에 압축 해제한다. 기존 파일이 있다면 덮어쓰지 않는다.
3. 현재 프로젝트의 `.gitignore` 파일에 다음 줄을 **직접 추가**한다 (기존 `.gitignore` 내용을 지우지 않는다):
   `docs/references/private/`
4. `CODEX_FIRST_TASK.md` 전체를 Cursor의 Codex 패널에 붙여넣는다.
5. Codex가 참조 이미지를 실제로 확인했는지 점검하고 결과를 검토한다.

## 주의
스크린샷에 실제 사람 사진/이름 및 민감한 건강 정보가 담겨 있을 수 있다. 공개 저장소에 업로드하지 않도록 주의한다. `.gitignore` 추가 전에 `git add .`를 하지 말 것. 기존에 Git이 이미 추적 중이라면 `.gitignore`만으로 추적이 해제되지 않는다.

## 작업 목표
1차 작업은 원본 분석, 설계 문서, 위젯 미니 PoC까지다. 운영 DB 생성, 실사용자 데이터 처리, 앱 실제 배포는 별도 승인 후 진행한다.
